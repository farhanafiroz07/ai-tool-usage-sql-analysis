# AI Tool Usage by Indian College Students — SQL Analysis

## Project Overview
This project uses MySQL to analyze AI tool usage among Indian college students. It explores AI tool preferences, daily usage, awareness levels, willingness to pay, and students' perceptions of AI's impact on grades.

## Objectives
- Analyze AI tool usage patterns among students.
- Examine daily AI usage hours.
- Explore willingness to pay for AI tools.
- Study AI awareness and reported academic impact.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## SQL Queries
The file `ai_tool_usage_analysis.sql` contains the SQL queries used in this project.

## Dataset
AI Tool Usage by Indian College Students 2025.
